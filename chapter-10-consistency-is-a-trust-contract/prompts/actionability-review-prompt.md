# Actionability Review Prompt

Review my system design answer and identify the actionability cliff.

For each major state or value, classify it as:

- Informational
- Advisory
- Actionable
- Irreversible / committed

Then identify:
- Where stale data is acceptable
- Where stale data becomes dangerous
- What evidence is required before action
- What UI/API label should be used
- What degraded state should be shown if proof is missing
