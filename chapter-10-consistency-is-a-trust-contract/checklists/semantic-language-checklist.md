# Semantic Language Checklist

For every state label, define:

- What does this label mean?
- What evidence is required?
- Can the user act?
- Can automation act?
- Can AI say this word?
- Is there an expiration time?
- What is the next valid transition?
- What compensation exists if the transition fails?

High-risk words:

- Available
- Held
- Reserved
- Pending
- Confirmed
- Settled
- Final
- Approved
