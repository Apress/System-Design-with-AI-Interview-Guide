# Actionability Cliff Checklist

Ask:

- Can the user act on this value?
- Is the value informational, advisory, actionable, or irreversible?
- What happens if the value is stale?
- What proof is required before action?
- What should the UI/API label be?
- Should the system block, defer, or escalate?
- What state should be shown if proof is delayed?
- Who owns the commitment?
