# High-Level Architecture Readiness Checklist

Before presenting your architecture, confirm that you can explain:

- Who the users and actors are
- What business capabilities the architecture supports
- Which services own which outcomes
- Which data stores are systems of record
- Which paths are synchronous
- Which paths are asynchronous
- Where events or queues are used
- Which external dependencies are critical
- Where AI fits
- What AI is not allowed to do
- How failures degrade
- What is logged for observability and replay
- Which security boundaries matter
- Which trade-off you are defending
