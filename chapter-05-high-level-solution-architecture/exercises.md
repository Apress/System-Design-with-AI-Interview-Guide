# Chapter 5 Exercises

## Exercise 1: High-Level Architecture Warm-Up

Design a high-level architecture for DreamMart, including user-facing channels, core capabilities, systems of record, messaging, external integrations, AI/ML components, observability, and security boundaries.

## Exercise 2: Architecture Views

Improve a crowded one-page architecture diagram by splitting it into multiple views such as context, service, data flow, runtime sequence, failure/degradation, and AI trust/evidence views.

## Exercise 3: Synchronous vs. Asynchronous Design

For DreamMart checkout, decide which operations must complete before order confirmation and which can happen asynchronously after the customer receives a response.

## Exercise 4: AI Architecture Integration

Place AI shopping assistant, recommendations, fraud scoring, support summarization, and delivery prediction into the high-level architecture without giving AI unsafe authority.

## Exercise 5: Senior Architect Trade-Off Defense

Defend your high-level architecture when challenged that it is too complex and should be replaced with one database, one backend service, and direct AI model calls.
