# AI Architecture Review Prompt

Review my AI-enabled architecture.

Evaluate:

- Whether each AI feature belongs in the architecture
- Whether it is advisory, assistive, or automated
- Whether it is safely placed inside or outside the critical path
- What evidence it uses
- Whether tool access is properly bounded
- What deterministic validation is needed
- What happens when confidence is low
- What should be logged for replay
- Whether any AI component has hidden authority

Then propose a safer and more production-ready AI architecture.
