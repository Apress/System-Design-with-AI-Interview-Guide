# Commitment Review Prompt

Review my design and identify commitment problems.

For each customer-visible claim, determine:

- Whether it is provisional or committed
- What proof is required before saying it
- Which system of record owns the truth
- What state should be shown while pending
- What AI must not say
- Whether the action is reversible
- What commit token or evidence should exist

Then rewrite the design so the system does not overclaim.
