# Decision Replay Card Review Prompt

Review my AI-involved decision design.

Create a Decision Replay Card that includes:

- Correlation ID
- Capability
- Decision and mode
- Acting principal and represented role
- Authority envelope version
- Policy and guardrail versions
- Evidence sources
- Tool calls
- Model and prompt versions
- Commit token
- Customer-visible outcome
- Reversal or remediation link

Then identify any missing evidence that would make the decision hard to defend later.
