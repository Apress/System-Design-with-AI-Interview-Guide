# Chapter 14 Companion Resources: Ride-Sharing Systems

This folder contains companion practice material for Chapter 14 of *System Design with AI Interview Guide*.

Use these resources after reading the chapter to practice designing ride-sharing systems as real-time marketplace commitment engines. The focus is not only matching riders to drivers. The focus is hold versus commit, freshness budgets, bounded churn, defensible pricing, fairness guardrails, inference-DAG budgets, phase-aware conflict handling, safety hard stops, and replayable evidence.

## How to use this folder

1. Start with `exercises.md`.
2. Compare your answers with `solution-guide.md`.
3. Use schemas and policies to make the design concrete.
4. Use worksheets to map the earlier lenses from the book into the applied ride-sharing design.
5. Use simulations and test cases to pressure-test the design.

For the full explanation, narrative examples, and chapter walkthrough, refer to the book.
