# Ride-Sharing 7-Step Method Map

Use this worksheet to map the 7-Step System Design Method to ride-sharing.

| Step | Ride-Sharing Application | Notes |
|---|---|---|
| Clarify | Matching only or full marketplace lifecycle? |  |
| Actors | Rider, driver, marketplace, platform, support, regulator. |  |
| Journey | Request, quote, hold, acceptance, commit, pickup, trip, payment, support. |  |
| Constraints | Real-time movement, GPS freshness, city policy, pricing, fairness, safety. |  |
| Commitments | Quote, hold, match, ETA, cancellation, compensation, payment. |  |
| Architecture | Location, search, ranking, dispatch, commit gate, pricing, fairness, replay. |  |
| Trade-offs | Speed vs admissibility; optimization vs churn; autonomy vs safety. |  |
