# LLM-SHIELD Readiness Checklist

Before releasing an AI capability, confirm:

- Unacceptable failures are scoped
- Attack surfaces are mapped
- Prompts are versioned
- Policies are versioned
- Guardrails are tested
- RAG sources are scoped
- Retrieval is access-controlled
- Memory is bounded
- Tools are allowlisted
- Autonomy level is defined
- Confidence gates exist
- Human review points exist
- Runtime defense exists
- Replay coverage exists
- Scorecard exists
- Red-team/blue-team cadence exists
