# Prompt and Policy Hardening Checklist

Check that:

- System prompts are versioned
- Policy bundles have owners
- Guardrail thresholds are reviewed
- Tool definitions are classified by side effect
- RAG configuration is tested
- Golden conversations exist
- Jailbreak tests exist
- Prompt injection tests exist
- Refusal-line tests exist
- Canary release exists
- Rollback path exists
- Production signals are monitored after change
