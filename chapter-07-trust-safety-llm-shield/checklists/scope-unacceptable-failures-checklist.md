# Scope and Unacceptable Failures Checklist

Define:

- What must never happen?
- Which customer commitments require proof?
- Which financial actions are forbidden?
- Which policy answers require citation?
- Which actions require human review?
- Which evidence is admissible?
- Which evidence is explanatory only?
- Which data sources are untrusted?
- Which tool calls are dangerous?
- Which failures require refusal?
