# Live-Defense Observability Checklist

Monitor:

- Prompt injection attempts
- Jailbreak attempts
- Sensitive-data leakage
- Unsafe output
- Guardrail hit rate
- Blocked-action count
- Escalation rate
- Reversal count
- Tool failure rate
- Retrieval anomaly rate
- Policy-version drift
- Evidence-snapshot gaps
- Replay coverage
- Cost per successful action
- Latency and timeout patterns
