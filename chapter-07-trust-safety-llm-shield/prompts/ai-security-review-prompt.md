# AI Security Review Prompt

Review my AI-enabled architecture using LLM-SHIELD.

Evaluate:

- Scope: unacceptable failures and attack surface
- Harden: prompts, policies, guardrails, tests, rollback
- Isolate: retrieval, memory, tools, and data paths
- Empower: autonomy levels and permission gates
- Live-Defend: AI firewall, runtime policies, observability, kill switch
- Demonstrate: scorecards, red-team/blue-team loops, governance evidence

Then identify the top five security risks and propose concrete mitigations.
