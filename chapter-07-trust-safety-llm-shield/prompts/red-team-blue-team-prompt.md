# Red-Team / Blue-Team Prompt

Act as a red-team and blue-team reviewer for my AI-enabled capability.

Red team:
- Identify prompt injection attacks
- Identify jailbreak paths
- Identify retrieval poisoning paths
- Identify context stuffing risks
- Identify tool-abuse paths
- Identify data leakage paths
- Identify excessive-autonomy risks

Blue team:
- Propose controls for each attack
- Add tests
- Add guardrails
- Add monitoring
- Add replay evidence
- Add incident playbooks

End with:
1. Top five threats
2. Top five mitigations
3. Tests to add
4. Runtime signals to monitor
5. Residual risks
