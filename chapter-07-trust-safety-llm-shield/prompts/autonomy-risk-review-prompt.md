# Autonomy Risk Review Prompt

Review my AI agent design and classify each action by autonomy level:

- Level 0: Observe only
- Level 1: Suggest
- Level 2: Act with approval
- Level 3: Bounded autonomy
- Restricted: Never act directly

For each action, identify:

- Risk level
- Evidence required
- Approval requirement
- Rollback path
- Rate limit
- Kill switch
- Replay requirement

Then recommend where autonomy should be reduced.
