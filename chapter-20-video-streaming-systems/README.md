# Chapter 20 Companion Resources: Video Streaming Systems

This folder contains companion practice material for Chapter 20 of *System Design with AI Interview Guide*.

Use these resources after reading the chapter to practice designing video streaming systems as continuous-experience commitment engines. The focus is not only HLS, DASH, encoders, manifests, CDNs, and players. The focus is session-grant authority, entitlement proof, manifest integrity, DRM evidence, CDN routing receipts, ABR control, ad side effects, low-latency mode, stop authority, ROCS control loops, and replayable QoE proof.

## How to use this folder

1. Start with `exercises.md`.
2. Compare your answers with `solution-guide.md`.
3. Use schemas, policies, and manifests to make the design concrete.
4. Use worksheets to apply the earlier lenses from the book.
5. Use simulations and test cases to pressure-test the design.
6. Use prompts to practice senior-level interview defense.

For the full explanation, narrative examples, and chapter walkthrough, refer to the book.
