# Economics Readiness Checklist

Before scaling a high-cost capability, confirm:

- Unit of value is defined
- Unit cost is defined
- Cost is measured by capability
- Cost is attributed to execution path
- Retrieval fan-out is capped
- Tool calls are capped
- Retries are budgeted
- Token budget exists
- Model-tier rules exist
- Human rework is tracked
- Sustainability metric exists
- Runtime enforcement exists
- Stop authority is named
