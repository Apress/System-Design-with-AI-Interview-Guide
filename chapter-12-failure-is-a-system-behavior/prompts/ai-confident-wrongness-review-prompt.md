# AI Confident Wrongness Review Prompt

Review my AI-enabled capability for confident-wrongness risks.

Check whether the AI can:

- Answer with non-authoritative evidence
- Act when evidence conflicts
- Trigger tools without proof
- Treat support articles as authoritative
- Ignore system-of-record state
- Continue when it should defer or escalate

Then design:
- Admissible evidence gate
- Confidence gate
- Authority boundary
- Escalation rule
- Hard stop rule
- Replay evidence
