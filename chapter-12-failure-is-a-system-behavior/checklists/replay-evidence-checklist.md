# Replay Evidence Checklist

Capture:

- Correlation ID
- Capability
- User/customer context
- Timestamp
- Failure signal
- Dependency state
- Policy version
- Evidence freshness
- State snapshot
- Evidence sources
- Conflicts
- Missing evidence
- Tool calls
- AI prompt/model version, if applicable
- Decision mode
- Human approval
- Customer-visible outcome
- Compensation/remediation link
