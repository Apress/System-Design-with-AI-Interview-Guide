# Chapter 24 Companion Resources: Designing for Uncertainty Is the Job Now

This companion lab helps software developers and architects practice the final synthesis of the book across any system: checkout, ride-sharing, payments, fraud, file storage, search, streaming, and AI agents.

Core pattern:

> Name the commitment, define admissible reality, bound churn, leave a receipt, and give the system authority to stop.

## How to use

1. Start with `exercises.md`.
2. Compare with `solution-guide.md`.
3. Use worksheets before drawing architecture.
4. Use schemas and policies to make the method concrete.
5. Use simulations and examples to practice senior interview defense.
