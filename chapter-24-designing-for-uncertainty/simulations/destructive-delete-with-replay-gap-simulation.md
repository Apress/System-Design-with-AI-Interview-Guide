# Destructive Delete With Replay Gap Simulation

## Scenario

A production system is technically available, but a high-stakes claim becomes unsafe because evidence, freshness, receipts, budgets, or policy versions are weak.

## Analyze

- Which commitment boundary was crossed?
- Which evidence was stale, missing, or conflicting?
- Which churn budget failed?
- Which stop authority should fire?
- What replay evidence is missing?
- What recovery and re-enable proof is required?
