# Chapter 17 Companion Resources: Messaging Systems

This folder contains companion practice material for Chapter 17 of *System Design with AI Interview Guide*.

Use these resources after reading the chapter to practice designing messaging systems as side-effect commitment engines. The focus is not only Kafka, queues, topics, partitions, consumer groups, and DLQs. The focus is producer intent, event identity, business transaction identity, side-effect identity, durable idempotency, retry budgets, DLQ replay modes, ordering scope, stop authority, ROCS control loops, and replayable proof.

## How to use this folder

1. Start with `exercises.md`.
2. Compare your answers with `solution-guide.md`.
3. Use schemas, DDL, and policies to make the design concrete.
4. Use worksheets to apply the earlier lenses from the book.
5. Use simulations and test cases to pressure-test the design.
6. Use prompts to practice senior-level interview defense.

For the full explanation, narrative examples, and chapter walkthrough, refer to the book.
