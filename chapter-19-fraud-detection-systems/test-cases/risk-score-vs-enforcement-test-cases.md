# Risk Score vs Enforcement Test Cases

| Case | Risk Score | Evidence | Expected Behavior |
|---|---:|---|---|
| High score only | 0.92 | Tier 1 missing | Step-up/review, no hard enforcement. |
| High score + Tier 1 supports | 0.93 | Fresh identity/payment issue | Enforcement candidate. |
| Medium score + soft signals | 0.65 | Tier 3 only | Step-up or monitor. |
| Low score + hard constraint | 0.10 | Sanctions hit | Block/route to compliance. |
