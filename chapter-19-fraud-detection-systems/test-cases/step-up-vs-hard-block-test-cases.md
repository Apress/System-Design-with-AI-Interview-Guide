# Step-Up vs Hard Block Test Cases

| Case | Uncertainty | Evidence | Expected Control |
|---|---|---|---|
| New device, clean Tier 1 | Medium | Clean | Step-up. |
| Identity missing due provider outage | High | Missing | Step-up fallback/review, avoid hard block. |
| Strong Tier 1 fraud evidence | Low | Bad | Hard enforcement if replay ready. |
| Replay gap | Any | incomplete | Freeze liability action. |
