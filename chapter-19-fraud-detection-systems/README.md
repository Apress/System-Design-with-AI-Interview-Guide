# Chapter 19 Companion Resources: Fraud Detection Systems

This folder contains companion practice material for Chapter 19 of *System Design with AI Interview Guide*.

Use these resources after reading the chapter to practice designing fraud detection systems as authority allocation systems. The focus is not only events, feature stores, fraud models, rules engines, scoring, and case queues. The focus is advisory risk, enforcement authority, evidence tiers, freshness, label delay, reversibility, stop authority, ROCS control loops, and replayable proof.

## How to use this folder

1. Start with `exercises.md`.
2. Compare your answers with `solution-guide.md`.
3. Use schemas and policies to make the design concrete.
4. Use worksheets to apply the earlier lenses from the book.
5. Use simulations and test cases to pressure-test the design.
6. Use prompts to practice senior-level interview defense.

For the full explanation, narrative examples, and chapter walkthrough, refer to the book.
