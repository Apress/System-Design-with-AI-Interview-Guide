# Fraud 7-Step Method Map

| Step | Fraud Application | Notes |
|---|---|---|
| Clarify | Transactions, refunds, payouts, account access, seller risk, or full lifecycle? |  |
| Actors | Customer, seller, fraud ops, appeals, compliance, finance, payments, support. |  |
| Journey | Event, score, evidence, step-up/enforcement, appeal, labels. |  |
| Constraints | Label delay, stale evidence, false enforcement, provider degradation, replay gaps. |  |
| Commitments | riskDecisionId, stepUpChallengeId, enforcementId, refundDenyId, payoutHoldId. |  |
| Architecture | Intake, scoring, evidence gate, step-up, enforcement, appeal, feedback, replay. |  |
| Trade-offs | Fraud loss vs false enforcement, speed vs proof, automation vs review. |  |
