# Capability-to-Service Readiness Checklist

Do not create services until you can explain:

- Which capability the service supports
- Which business outcome it owns
- Which state it owns
- Which API commands it accepts
- Which queries it supports
- Which events it emits
- Which dependencies are synchronous
- Which dependencies are asynchronous
- What happens when dependencies fail
- Whether AI is allowed to suggest, decide, or commit
- What evidence and replay records are required
