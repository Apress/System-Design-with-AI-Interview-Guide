# Latency Replay Review Prompt

Review my latency incident design.

Tell me whether I can answer this question six months later:

“Why did the user wait, what state did we show, what evidence existed, and why did the system later commit or fail?”

Identify missing fields:

- Correlation ID
- Idempotency key
- User context
- Decision timestamp
- Policy version
- Evidence sources
- Queue depth
- Retry count
- Tool calls
- Human approval
- Final outcome
- Reversal link
