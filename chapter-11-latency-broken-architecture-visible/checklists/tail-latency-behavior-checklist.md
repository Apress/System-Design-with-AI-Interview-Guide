# Tail Latency Behavior Checklist

Check for:

- Refreshes
- Duplicate clicks
- Repeated submissions
- App restarts
- Device switching
- Support escalation
- Repeated tool calls
- Retry storms
- Queue growth
- Public complaints

Controls:

- Idempotency
- Bounded retries
- Rate limits
- Backpressure
- Clear state
- Priority queues
