# Latency Myths Checklist

Watch for these dangerous statements:

- We can hide latency with UX.
- We can always add capacity.
- Average latency is good enough.
- Users will wait if the spinner is nice.
- Async processing solves the problem.
- The model call is the only AI latency.
- Retry until it works.

Replace with:

- Show honest state.
- Budget by journey moment.
- Make retries bounded and idempotent.
- Use backpressure.
- Preserve replay evidence.
- Budget the full AI DAG.
