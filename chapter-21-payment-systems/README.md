# Chapter 21 Companion Resources: Payment Systems

This folder contains companion practice material for Chapter 21 of *System Design with AI Interview Guide*.

Use these resources to practice designing payment systems as liability commitment engines, not merely gateway, ledger, webhook, queue, and retry pipelines.

## How to use this folder

1. Start with `exercises.md`.
2. Compare your answers with `solution-guide.md`.
3. Use schemas, DDL, and policies to make the design concrete.
4. Use worksheets to apply earlier lenses from the book.
5. Use simulations and test cases to pressure-test the design.
6. Use prompts to practice senior-level interview defense.
