# Search 7-Step Method Map

| Step | Search Application | Notes |
|---|---|---|
| Clarify | Product, policy, support, operational, or AI answer search. |  |
| Actors | User, source owner, crawler, parser, indexer, ranker, policy, AI, auditor. |  |
| Journey | Query, route, retrieve, rank, filter, cite, answer, replay. |  |
| Constraints | Index lag, stale cache, ranking drift, weak citations, vector errors. |  |
| Commitments | indexReceiptId, rankPolicyId, filterReceiptId, citationReceiptId, answerReceiptId. |  |
| Architecture | Crawl, parse, index, retrieve, rank, filter, cite, answer, replay. |  |
| Trade-offs | Speed vs freshness, recall vs authority, AI fluency vs proof. |  |
