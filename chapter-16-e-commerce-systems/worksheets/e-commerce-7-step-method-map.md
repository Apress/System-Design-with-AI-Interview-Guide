# E-Commerce 7-Step Method Map

| Step | E-Commerce Application | Notes |
|---|---|---|
| Clarify | Store infrastructure or commitment engine? |  |
| Actors | Customer, catalog, pricing, inventory, payment, fraud, warehouse, carrier, support, policy. |  |
| Journey | Browse, cart, checkout, payment, fulfillment, delivery, modification, return, refund. |  |
| Constraints | Hot SKUs, stale inventory, payment ambiguity, fulfillment cutoff, fraud, policy. |  |
| Commitments | Hold, reserve, authorize, commit, release, ship, refund. |  |
| Architecture | Services plus tokens, stop authority, replay. |  |
| Trade-offs | Speed vs proof, convenience vs cutoff, automation vs review. |  |
