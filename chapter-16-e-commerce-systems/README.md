# Chapter 16 Companion Resources: E-Commerce Systems

This folder contains companion practice material for Chapter 16 of *System Design with AI Interview Guide*.

Use these resources after reading the chapter to practice designing e-commerce systems as defensible commitment engines. The focus is not only catalog, cart, checkout, payment, inventory, and fulfillment. The focus is hold versus commit, admissible freshness, tokenized business commitments, checkout idempotency, fulfillment cutoffs, refund defensibility, stop authority, ROCS control loops, and replayable evidence.

## How to use this folder

1. Start with `exercises.md`.
2. Compare your answers with `solution-guide.md`.
3. Use schemas and policies to make the design concrete.
4. Use worksheets to apply the earlier lenses from the book.
5. Use simulations and test cases to pressure-test the design.
6. Use prompts to practice senior-level interview defense.

For the full explanation, narrative examples, and chapter walkthrough, refer to the book.
