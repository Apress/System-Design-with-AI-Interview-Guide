# Social Networking 7-Step Method Map

| Step | Social Networking Application | Notes |
|---|---|---|
| Clarify | Feed serving, discovery, trending, search, notifications, moderation, or full influence lifecycle? |  |
| Actors | Viewer, creator, moderator, advertiser, policy owner, regulator, platform. |  |
| Journey | Create, grant, discover, amplify, report, moderate, appeal, replay. |  |
| Constraints | Viral spread, policy, mode boundary, fairness, safety, replay, harm velocity. |  |
| Commitments | Visibility grant, amplification token, notify token, moderation action. |  |
| Architecture | Creation, eligibility, ranking, evidence gate, surface authority, replay. |  |
| Trade-offs | Push vs pull, relevance vs admissibility, engagement vs safety. |  |
