# Bottleneck Analysis Checklist

Analyze bottlenecks across:

- Compute
- Storage
- Network
- External dependencies
- Queues
- Policy/human review
- AI inference

For each one, ask:

- What does it look like?
- Which promise does it threaten?
- What telemetry reveals it?
- What scaling pattern helps?
- What trade-off does that pattern introduce?
