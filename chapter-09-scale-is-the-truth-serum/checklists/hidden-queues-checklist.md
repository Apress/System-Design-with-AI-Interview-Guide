# Hidden Queues Checklist

Look for queues in:

- Inventory checks
- Payment authorization
- Fraud review
- Tax calculation
- Fulfillment release
- Notification delivery
- AI inference
- RAG retrieval
- Tool calls
- Human approval

For each queue, define:

- Is the work advisory, provisional, or committed?
- What happens when it backs up?
- What does the user see?
- Is backpressure needed?
- Is priority needed?
- Is a pending state needed?
