# Bottleneck Analysis Review Prompt

Review my scale design and identify bottlenecks.

Analyze:

- Compute bottlenecks
- Storage bottlenecks
- Network bottlenecks
- External dependency bottlenecks
- Queue bottlenecks
- Policy/human bottlenecks
- AI inference bottlenecks

For each, explain:
1. What it looks like
2. What promise it threatens
3. What telemetry reveals it
4. What design response helps
5. What trade-off the response introduces
