# AI Scale Pressure Review Prompt

Review my AI-enabled system design for scale risks.

Look for:

- Retrieval fan-out
- Prompt expansion
- Tool-call loops
- Model-tier escalation
- GPU queue buildup
- Evaluation loops
- Retry cascades
- Token drift
- Missing budgets
- Missing fallback or degradation path

Then propose budgets, telemetry, and degradation controls.
