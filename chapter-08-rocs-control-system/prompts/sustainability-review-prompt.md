# ROCS Sustainability Review Prompt

Review my AI architecture for sustainability.

Evaluate both:

1. Responsible compute
2. Governable change

Check for:

- Carbon-aware routing
- Time-shifted inference
- Low-precision hardware
- Quantization
- Smaller model tiering
- Reduced data movement
- Useless inference hops
- Policy/model/vendor/team/region drift

Then propose a sustainability scorecard.
