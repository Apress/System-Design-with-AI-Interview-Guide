# Cost Governance Checklist

Check whether the system has budgets for:

- Retries
- Tool calls
- Retrieval fan-out
- Token usage
- Latency at commitment
- Evidence coverage
- Model tier
- GPU queue depth
- Batch workloads
- Manual cleanup

For each budget, define:

- Limit
- Owner
- Action when exceeded
- Evidence captured
- Re-enable criteria
