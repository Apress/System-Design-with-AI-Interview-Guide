# Instrumented Indecision Checklist

Red flags:

- Dashboards exist but no one can stop behavior
- Alerts fire but no thresholds map to actions
- Postmortems happen but controls do not change
- Replay gaps are visible but automation continues
- Cost spikes are visible but budgets are missing
- Tool failures increase but autonomy is not reduced
- Ownership is discussed but not executable

Fix by defining:

- Decision owner
- Stop thresholds
- Scoped blast radius
- Behavior changes
- Re-enable criteria
- Proof of intervention
