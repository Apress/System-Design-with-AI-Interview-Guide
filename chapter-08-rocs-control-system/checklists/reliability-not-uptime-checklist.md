# Reliability Is Not Uptime Checklist

Ask:

- What promise must still hold?
- Where is the commitment point?
- What proof is required before commitment?
- What happens when proof is delayed?
- What pending state exists?
- What retries are allowed?
- What retries are forbidden?
- Is idempotency enforced?
- Is single-flight needed?
- Does degradation preserve trust?
- Does the user see an honest state?
