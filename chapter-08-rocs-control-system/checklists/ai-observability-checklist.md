# AI Observability Checklist

ROCS-grade observability should include:

- Prompt-level tracing
- Prompt template version
- Token count
- Structured prompt logs
- Vector query telemetry
- Retrieval fan-out
- Reranker scores
- GPU queue depth
- Batch variance
- Tool-call traces
- Multi-agent span correlation
- Safety metrics
- Policy version
- Evidence snapshot
- Decision replay
- Reversal link
