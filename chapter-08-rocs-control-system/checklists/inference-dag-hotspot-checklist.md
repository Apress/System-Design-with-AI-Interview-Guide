# AI Inference DAG Hotspot Checklist

Check each DAG hop:

- API gateway
- Planner
- Intent classifier
- Retriever
- Vector database
- Reranker
- Prompt builder
- LLM router
- Model call
- Tool call
- Evaluator
- Memory
- Logger
- Escalation path

For each hop, identify:

- Latency risk
- Retry risk
- Cost risk
- Carbon risk
- Observability signal
- Degradation behavior
