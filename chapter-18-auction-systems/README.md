# Chapter 18 Companion Resources: Auction Systems

This folder contains companion practice material for Chapter 18 of *System Design with AI Interview Guide*.

Use these resources after reading the chapter to practice designing auction systems as adversarial marketplace commitment engines. The focus is not only bidding, leaderboards, WebSockets, Redis, Kafka, and winner notifications. The focus is close semantics, admissible bids, policy pins, commitment tokens, price-formation rules, fraud containment, settlement side effects, stop authority, and replayable proof.

## How to use this folder

1. Start with `exercises.md`.
2. Compare your answers with `solution-guide.md`.
3. Use schemas, DDL, and policies to make the design concrete.
4. Use worksheets to apply the earlier lenses from the book.
5. Use simulations and test cases to pressure-test the design.
6. Use prompts to practice senior-level interview defense.

For the full explanation, narrative examples, and chapter walkthrough, refer to the book.
